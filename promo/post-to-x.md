# X/Twitter Promo Posting Guide

## Quick Start

Use the X MCP `Post` tool in Claude Code to publish tweets from `tweets.json`.

### Post a tweet
```
Use the Post MCP tool with the text from tweets.json entry #N
```

## Schedule

- **Week 1 (Launch):** 2 posts/day — mix taglines (#1, #5), excerpts (#2, #4), and hooks (#3)
- **Week 2-3:** 1 post/day — rotate through remaining excerpts and questions
- **Week 4+:** 3-4 posts/week — mix personal stories with excerpts

### Best posting times
- 8-9 AM CT (morning commute)
- 12-1 PM CT (lunch break)
- 7-9 PM CT (evening wind-down)

## Tweet Categories

| Type | IDs | Best for |
|------|-----|----------|
| **tagline** | 1, 15 | Launch day, pinned tweet |
| **excerpt** | 2, 4, 6, 8, 10, 12, 14, 16, 18 | Daily rotation |
| **hook** | 3, 9, 20 | Engagement drivers |
| **question** | 7, 11, 17 | Conversation starters |
| **personal** | 5, 13, 19 | Authenticity, weekend posts |

## Tips

- Pin tweet #1 (the tagline) to your profile
- Reply to your own tweets with the book link for thread visibility
- Quote-tweet excerpts with personal context
- Engage with replies — the algorithm rewards conversation
